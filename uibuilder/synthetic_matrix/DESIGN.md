## Brand & Style

This design system establishes an ultra-sleek, technical, and high-performance dark aesthetic engineered specifically for data architecture, distributed intelligence, and enterprise-grade infrastructure. Moving beyond conventional corporate software styles, it takes cues from modern developer-first environments and cybernetic data control planes: deep abyssal dark canvas tones (slate-950, void obsidian), crisp geometric telemetry typography, and high-energy neon emerald signal accents that denote active system flow and live computational state.

The target audience consists of Chief Technology Officers, VP of Engineering leaders, data pipeline engineers, and enterprise technical stakeholders who demand reliability, computational authority, and zero latency. The visual tone balances industrial precision with polished modernism—communicating algorithmic rigor, institutional security, and continuous real-time clarity.

### Visual Architecture
- **Style:** Modern Dark Mode Minimalism fused with Cybernetic Telemetry.
- **Atmosphere:** Deep obsidian and slate surfaces layered with micron-thin translucent borders, subtle luminescence, and hyper-targeted emerald state indicators.
- **Metaphor:** The dynamic binary tree and network topology—nodes, synchronous pulses, clean edge conduits, and telemetry clusters.

## Colors

The chromatic architecture is constructed to maximize contrast, minimize ocular fatigue in 24/7 technical environments, and isolate signal from noise. The foundation is built upon deep void tones (`#05070c` and `#090d16`), establishing a pitch-black yet rich backdrop that elevates dense metrics without visual vibration.

### Palette Roles & Usage
- **Primary (`#00f090` - Luminous Emerald):** The chief interactive signal and active telemetry status. Used for core actions, live indicators, focused states, and directional paths in pipeline diagrams.
- **Secondary (`#10b981` - Deep Mint):** Supporting brand accent, active toggles, inline badges, and secondary high-confidence verification tags.
- **Tertiary (`#064e3b` - Emerald Deep Void):** Subdued contextual fills, hover states on badges, and gradient terminal stops.
- **Neutral Canvas (`#090d16` / `#05070c`):** Deep slate-obsidian neutral foundation for all dashboards, surface layers, and architectural panels.
- **Functional Telemetry Signals:** `signal-cyan` (`#38bdf8`) for ingress data streams, `signal-amber` (`#f59e0b`) for pipeline latency warnings, and `signal-crimson` (`#f43f5e`) for node drops or cluster faults.

## Typography

The typographic hierarchy prioritizes technical legibility, geometric structure, and information density:

1. **Headlines (`Geist`):** Engineered for ultra-clean rendering on modern displays. Tight negative letter-spacing gives an authoritative, contemporary tech signature.
2. **Body Copy (`Inter`):** Selected for its neutral tone, tall x-height, and optimal reading ergonomics across complex architectural documentation and dense operational dashboards.
3. **Telemetry & Code (`JetBrains Mono`):** Applied to telemetry values, node statuses, table timestamps, JSON structures, schema labels, and technical badges to reinforce the infrastructural character of the product.

## Layout & Spacing

This design system uses a strict 8-point base spacing grid nested inside a fluid 12-column layout. Structural containers align with mathematical precision to reflect the engineering integrity of data pipelines.

### Breakpoints & Adaptive Strategy
- **Mobile (< 768px):** 4-column layout, `margin`: `1rem`, `gutter`: `1rem`. All data card grids collapse to single-column streams. Telemetry metrics condense into scrolling metric rails.
- **Tablet (768px – 1024px):** 8-column layout, `margin`: `1.5rem`, `gutter`: `1.25rem`. Two-column card arrangements with stacked pipeline flowcharts.
- **Desktop (1024px – 1440px):** 12-column layout, max content boundary `1280px`, `margin`: `2rem`, `gutter`: `1.5rem`.
- **Wide Workstation (> 1440px):** Expands to max content boundary `1400px` for high-density multi-pane system dashboards.

## Elevation & Depth

Visual hierarchy is constructed via tonal surface layering, ultra-fine luminescence, and subtle glassmorphism rather than muddy drop shadows.

### Elevation Levels
- **Ground Floor (Canvas - Level 0):** `#05070c` base background with optional micro-grid architectural dot patterns (`#1e293b` at 12% opacity).
- **Surface Level 1 (Panels & Cards):** `#0c111d` with a solid 1px border of `rgba(255, 255, 255, 0.07)`. Non-interactive elements rest here.
- **Surface Level 2 (Elevated & Active Cards):** `#131b2e` with a 1px border of `rgba(255, 255, 255, 0.12)`. When active or hovered, border transitions to `rgba(0, 240, 144, 0.35)` with an ambient back-glow: `box-shadow: 0 0 24px -4px rgba(0, 240, 144, 0.12)`.
- **Floating Overlays & Modals (Level 3):** Glassmorphic surface `#0c111de6` featuring `backdrop-filter: blur(16px)` and perimeter rim lighting `1px solid rgba(255, 255, 255, 0.15)`.
- **Active Node Glow:** Interactive data points and system status indicators project a localized radial glow `box-shadow: 0 0 12px rgba(0, 240, 144, 0.45)`.

## Shapes

The design system adopts a disciplined, modern **Soft (`1`)** roundedness profile. This prevents UI components from appearing overly toy-like or consumer-casual, reinforcing the technical precision required for enterprise infrastructure.

- **Component Base Radius:** `0.25rem` (4px) for controls, inputs, and inline telemetry indicators.
- **Cards & Data Modules:** `0.5rem` (8px) for modular pipeline nodes and service cards.
- **Large Panels & Overlays:** `0.75rem` (12px) for dashboard canvas modules and modal dialogs.
- **Pills / Status Dots:** Fully rounded (`9999px`) exclusively reserved for live telemetry status chips and active system badges.

## Components

### 1. Primary & Secondary Buttons
- **Primary Action (System Active):** Background `#00f090`, text `#05070c`, font `JetBrains Mono` 13px weight 600, uppercase letter-spacing +0.03em. On hover, background shifts to `#34d399` with `box-shadow: 0 0 20px rgba(0, 240, 144, 0.35)`.
- **Secondary Action (Subsystem Outline):** Background `rgba(255, 255, 255, 0.03)`, text `#f8fafc`, 1px border `rgba(255, 255, 255, 0.15)`. Hover triggers border `#00f090` and text `#00f090`.

### 2. Telemetry & Metric Badges
- **Status Pulse Badge:** Monospace font, padding 2px 8px, border-radius 9999px.
- **Live State:** Background `rgba(0, 240, 144, 0.1)`, text `#00f090`, with a pulsing 6px emerald dot (`animation: pulse 2s infinite`).
- **Warning State:** Background `rgba(245, 158, 11, 0.1)`, text `#f59e0b`.
- **Critical State:** Background `rgba(244, 63, 94, 0.1)`, text `#f43f5e`.

### 3. Pipeline & Service Cards
- Container built with `#0c111d`, 1px border `rgba(255, 255, 255, 0.08)`, radius `8px`.
- Card Header: Features a discrete index tag (e.g., `// 01`) in `JetBrains Mono` `#64748b` and an icon container with subtle emerald perimeter lighting.
- Card Body: High-contrast title in `Geist`, concise descriptive system specs in `Inter` `#94a3b8`.
- Hover Behavior: Border transitions smoothly to `rgba(0, 240, 144, 0.4)` accompanied by a subtle 12px outer emerald aura.

### 4. Input Fields & Search Controls
- Background `#05070c`, 1px border `#1e293b`, text `#f8fafc`, font `Inter` 14px.
- Focus state activates a distinct `#00f090` ring (`1px solid #00f090`) with an emerald focus-shadow: `0 0 0 2px rgba(0, 240, 144, 0.2)`. Placeholder text in `#475569`.

### 5. Checkboxes & Radio Controls
- Custom squared controls (checkbox radius 2px, radio radius 9999px) with dark base `#0c111d` and 1px border `#334155`.
- Selected state fills with `#00f090` and displays a pitch-black `#05070c` tick mark.

### 6. Data Stream Lists & Logs
- Alternating subtle rows using `#090d16` and `#0c111d`.
- Timestamp column in `JetBrains Mono` `#64748b`, event description in `Inter` `#f8fafc`, latency value right-aligned in `JetBrains Mono` `#00f090`.
